Technical description

Optimal input

One apical cine per run, preferably four-chamber; the model targets apical views (A4C, A2C, A3C). If several files are selected the first is used, so pick the apical loop first. At least 21 frames helps, because each inference uses seven context frames at offsets -9, -3, -1, 0, 1, 3, 9.

Grayscale B-mode without colour Doppler, measurements or screen-recording overlays.

Optimal way to use it

Eight temporal windows are sampled across the cine. Each window runs the seven-frame context stack and yields four heatmap layers: the endocardial curve, the apex, and the two mitral valve hinge points. Shortening is (max - min) / max of the curve length across windows.

This is contour shortening on a 608-pixel model grid, not speckle tracking and not a calibrated strain measurement.

Model and source

Weights: huggingface.co/AnupamK/panecho-onnx (pinned 07d2bb2). Source: UnityImaging/unity-gls at commit 3834c0e, HRNetV2M10, MIT licence. ONNX opset 17, FP32. PyTorch vs ONNX Runtime max absolute difference 5.9e-5.

Browser deviations: bilinear canvas resize rather than OpenCV INTER_AREA, assumed 30 fps for context offsets, and a square-stretched preview.
